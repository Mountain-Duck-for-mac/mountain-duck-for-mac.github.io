How It Works

1. Add a Connection

Open Mountain Duck from the menu bar, select your protocol, and enter server details. Bookmarks save credentials securely for one-click access.

2. Mount as Disk

Mount the volume—it appears on your Desktop and in Finder like any local drive. No virtual file systems or mounting commands required.

3. Work Seamlessly

Edit, sync, and back up files directly. Use any Mac app with full read/write support, including encryption for sensitive data.

4. Unmount Anytime

Eject the disk when done. Volumes stay bookmark-ready for instant remounting, with auto-reconnect on network changes.
